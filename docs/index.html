HotSlot

Historial de portapapeles, slots fijos y pegado automático en un clic. Todo local en tu Mac — sin nube, sin cuentas.

Descarga

La versión pública se distribuye fuera de la Mac App Store (Developer ID + notarización) para que el pegado automático funcione en Notas, Safari, Cursor y el resto de tus apps.

GitHub Releases

Verificá el SHA-256 publicado en cada release. macOS puede pedir abrir desde Ajustes la primera vez.

Permiso de Accesibilidad

HotSlot pide Accesibilidad solo para simular ⌘V y ⌘C en la app donde estabas. No leemos pantallas ni enviamos datos a internet.

  • Ajustes del Sistema → Privacidad y seguridad → Accesibilidad → activar HotSlot
  • Onboarding y Ajustes → Permisos dentro de la app
